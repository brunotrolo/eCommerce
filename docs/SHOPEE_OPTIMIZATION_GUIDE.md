# Guia de Otimização Shopee — Alta Conversão

Playbook baseado em research de best practices para otimizar listagens Shopee com foco em CTR, conversão e lucratividade.

**Última atualização:** 2026-08-11 | **Categoria:** Perfumaria

---

## 1. Otimização de Título (60–120 chars)

### Estrutura Recomendada
```
[BRAND] [PRODUCT TYPE] [KEY BENEFIT] [VOLUME] | [URGENCY or LAST LINE]
```

**Exemplo:**
```
✅ "Perfume Lattafa Yara Feminino 100ml EDP | Últimas Unidades"
   (Length: 58 chars, first 60 visible = 100% display)

❌ "Premium Lattafa Yara Feminino 100ml Eau de Parfum Original — Exclusive Luxury Fragrance"
   (Length: 89 chars, has buzzwords: Premium, Exclusive, Luxury = -9% CTR)
```

### Key Rules

1. **Char 1–20 = Most Critical**
   - Lead with primary keyword (what buyers search for)
   - Examples: "Perfume Árabe", "Fragrância Feminina", "EDP Original"
   - Char 20 should contain primary keyword

2. **Char 1–60 = Search Visibility**
   - Only first 60 chars visible in search results (non-click)
   - Every char after 60 requires user to click title to see
   - Prioritize keywords within 60 chars

3. **Char 61–120 = Click-Through Only**
   - Visible only after user clicks
   - Use for scarcity, benefit, or clarification
   - Example: "| Últimas Unidades" (7 chars, low priority)

4. **Avoid Redundancy**
   - Don't repeat "perfume perfume" or "fragrância fragrância"
   - Shopee algorithm penalizes keyword stuffing
   - Natural language ranks better than keyword-heavy

### Elements to Include (If Space)

| Element | Priority | Example | Chars |
|---|---|---|---|
| Brand | High | "Lattafa" | 7 |
| Product Type | High | "Perfume Feminino" | 16 |
| Volume | High | "100ml" | 5 |
| Formulation | Medium | "EDP" | 3 |
| Authenticity | Medium | "Original" | 8 |
| Urgency (if real) | Low | "Últimas Unidades" | 16 |

### Anti-Patterns to Avoid

❌ Brand duplication: "Lattafa Lattafa Yara"
❌ Buzzwords: "Premium", "Luxury", "Exclusive"
❌ ALL CAPS sections: "PERFUME ÁRABE"
❌ Abbreviations unclear: "Perf. Lat. Far. 100ml"
❌ False scarcity: "Last one!" (unless literal)

## 2. Otimização de Descrição (300–500 chars optimal)

### Estrutura Recomendada

**Section 1: Hook (1–2 sentences)**
```
Quer um perfume que dura o dia todo? Este Lattafa tem óleos concentrados 
que mantêm presença por 8+ horas.
```

**Section 2: Problem → Solution → Proof**
```
✗ Perfumes normais desbotam em 2–3 horas
✓ Lattafa Yara dura 8–12 horas (óleo concentrado)
✓ 1000+ reviews positivos | Importado oficial
```

**Section 3: Specifications (Bullets)**
```
- Volume: 100ml
- Tipo: Eau de Parfum (EDP)
- Fragrância: Oriental/Floral
- Concentração: 20% óleo puro
```

**Section 4: Usage Instructions (Reduz returns)**
```
Como usar:
1. Aplicar pequena quantidade no pulso
2. Aroma floresce após 15 minutos
3. Longevidade: 8+ horas com reaplica ção
```

**Section 5: Guarantee**
```
Satisfação garantida ou devolução sem perguntas.
EAN: 6291108735411
```

### Psychology Triggers (Legitimate)

| Trigger | Example | Impact | Condition |
|---|---|---|---|
| **Social Proof** | "1000+ compras, 4.8★" | +20% conversion | Show actual data |
| **Specificity** | "Óleos concentrados, 20% pureza" | +15% conversion | Verifiable |
| **Urgency (if real)** | "Stock limitado desta importação" | +10% conversion | Actually limited |
| **Scarcity** | "Apenas 3 unidades disponíveis" | +8% conversion | True inventory |
| **Authority** | "Distribuidor oficial" | +12% conversion | Verifiable |

### Format Guidelines

- **300–500 chars optimal** (scannable on mobile, sufficient for detail)
- **Line breaks every 2–3 sentences** (readability, not wall-of-text)
- **Bold key attributes** (`**volume: 100ml**`, `**EDP**`)
- **Emojis (sparingly):** ✓, ★, 🎁 (reduce cognitive load)
- **NO walls of text** (mobile-first: breaks required)

### Psychological Copy Techniques

**Loss aversion (frame as prevention, not gain):**
```
❌ "Our perfume lasts 8 hours" (framed as gain)
✅ "Evite perfumes que saem em 2–3 horas — este dura 8+" (frame as loss prevention)
```

**Specificity > generics:**
```
❌ "Ótimo aroma"
✅ "Notas de bergamota + cedro + almíscar — oriental floral clássico"
```

**Authority + scarcity combo:**
```
✅ "Distribuidor oficial | Importado direto de Dubai | Stock limitado nesta remessa"
```

## 3. Estratégia de Preço

### Psychological Pricing

**Charm pricing (end in 9 or 90):**
```
✅ R$89.90 vs R$90 → +3–5% perceived value
✅ R$149.99 vs R$150 → Feels under-threshold

Rule: Always end in 9 (or 90 if round number less appealing)
```

**Reference pricing (anchor higher):**
```
✅ "Concorrente cobra R$189 | Aqui R$149" 
   → Verify competitor price is real, not inflated

❌ Fake "Original Price: R$300" then "Sale: R$150"
   → Shopee penalizes (false discounts tank ranking)
```

**Tiered discounts (increase AOV):**
```
Pricing table:
- 1 unit: R$99.90
- 2–3 units: R$95.00 each
- 4+ units: R$89.90 each

Expected impact: +25–40% in multi-unit orders
```

**Dynamic pricing by demand:**
```
Low-demand period (0 sales/week): -10% (R$89.90)
Normal period: R$99.90
High-demand (seasonal): +5% (R$104.90)

Rule: Adjust max 1x/week. Frequent changes confuse buyers.
```

### Margin Protection

**Formula (PricingService):**
- Shopee fee: 20% (or 22% for premium)
- Net price = Sale price × (1 - fee_rate)
- Example: R$99.90 × 0.80 = R$79.92 net

**Minimum margin:** &gt;25% of net price recommended (absorbs returns, logistics)

## 4. Estratégia de Imagens (9 max, posições específicas)

### Posições Recomendadas

| # | Type | Spec | Purpose |
|---|---|---|---|
| 1 | **Hero** | Clean, white bg, 70% frame | Search results thumbnail |
| 2 | **Lifestyle** | In-use (hand, shelf) | Emotional connection, scale |
| 3 | **Detail** | Label close-up | Authentication, authenticity seal |
| 4 | **Angles** | Side/back view | Completeness, 3D perspective |
| 5 | **Scale** | Next to hand/coin/ruler | Size context (eliminates "surprised by size") |
| 6 | **Bundle** | If combo product | Context of multiple items |
| 7 | **Comparison** | vs. competitor (if legal) | Perceived value |
| 8 | **Authentication** | Seal/barcode/certificate | Trust signal for premium |
| 9 | **Extra** | Additional detail | Fills gallery for browsing |

### Quality Minimums

- **Resolution:** 500×500px minimum (Shopee displays 600×600)
- **Format:** JPG only (no WebP — Shopee rejects)
- **File size:** &lt;2MB (Shopee compresses anyway)
- **Lighting:** Consistent across images (no jarring color shifts)
- **Background:** White or neutral (no competing elements)

### Impact on Conversion

- 1–2 images: baseline 100%
- 3–5 images: +15% conversion
- 6–9 images: +30–40% conversion
- &gt;9 images: diminishing returns (platform cap)

## 5. Recursos Shopee (Deals, Vouchers, Bundles)

### Shopee Deals

**When to use:**
- Stock: &gt;2 units
- Duration: 24–48 hours
- Goal: Move inventory or acquire first-time buyers
- Impact: 3x–5x traffic spike during deal window

**Example:**
```
Regular price: R$99.90
Deal price: R$84.90 (15% off)
Duration: 48 hours
Units limited: 5

Expected: 8–12 conversions (vs. 2–3 normal)
```

**Caution:** Traffic drops after deal ends. Use strategically (not constantly).

### Shop Vouchers

**When to use:**
- Drive repeat visits (show in shop page)
- Create threshold incentive (min purchase)
- Impact: 25–40% of browsers use if threshold reasonable

**Example:**
```
Code: SUMMER15
Discount: 15%
Min spend: R$50
Duration: 30 days
```

### Bundles

**When to use:**
- 2–3 complementary products in stock
- Price discount bundled (perceived savings)
- Impact: +40–60% AOV, +15–20% conversion vs. single item

**Example:**
```
Bundle: "Perfume Lattafa + Lotion" 
Regular: R$99.90 + R$49.90 = R$149.80
Bundle: R$129.90 (R$19.90 savings)
```

### Flash Sales (Shopee Invites)

**When to use:**
- High inventory need to move
- Platform-wide visibility (Shopee promotes)
- Margin loss absorbed (thin margin acceptable for volume)

**Timeline:** Participate every 2–4 weeks (not constantly).

## 6. Fulfillment & Shipping Visibility

### Display Strategy

**Critical:** Always show shipping cost BEFORE checkout.

```
Listing should display:
"Frete Correios a partir de R$15 | Entrega em 5–10 dias | Rastreado"

Shopee does this automatically, but reinforce in description.
```

### Free Shipping Threshold

**Impact:** Reduces cart abandonment by 30–40%

**Setup:**
```
IF order > R$100 → Free shipping
ELSE → Standard shipping R$15–30 (varies by zone)
```

**ROI:** If margin &gt;25%, absorb shipping cost. Volume spike justifies it.

### Offer Multiple Options

**Optimal:** 2–3 clear options

```
1. Standard (5–7 days, Correios): R$15
2. Express (2–3 days, via Xpress): R$45
3. Free shipping (above R$100)
```

**Avoid:** &gt;5 options (decision paralysis, -CTR).

## 7. Gestão de Reviews

### Response Timeline

**Target: &lt;24 hours**

Shopee algorithm favors fast responses:
- Response &lt;12h: +visibility boost
- Response &lt;24h: +standard visibility
- Response &gt;48h: Minimal effect

### Response Templates

**5-star:**
```
"Obrigado pela confiança! Ficamos felizes que o produto agradou. 
Volte sempre! 🎁"
```

**3–4 star:**
```
"Valorizamos seu feedback! Qual foi o ponto de melhoria? 
Responda aqui ou mande mensagem privada para resolver."
```

**1–2 star:**
```
"Lamentamos que o produto não atendeu às expectativas. 
Podemos ajudar: Pix de retorno ou troca. Mande mensagem: [link]"
```

### Do's & Don'ts

✅ Thank 5-star reviewers (encourage repeat)
✅ Ask specific question on 3–4 star (shows engagement)
✅ Offer resolution privately on 1–2 star (avoid public negotiation)

❌ Don't promise refunds in review (escalate to support)
❌ Don't argue with negative reviews (hurts perception)
❌ Don't incentivize reviews with out-of-band payments (violates ToS)

## 8. Cart Abandonment Drivers & Mitigation

### Driver #1: Shipping Shock (20–30% abandonment)

**Solution:**
- Display shipping cost in listing (before click)
- Free shipping threshold (above R$100)
- Show estimated delivery date

**Impact:** -20% abandonment risk

### Driver #2: Slow Delivery (10–15% abandonment)

**Solution:**
- Offer express option (even if 5–10% take it)
- Display SLA clearly: "Entrega em 3–5 dias"
- Real-time tracking (Shopee provides, verify active)

**Impact:** -10% abandonment risk

### Driver #3: Unclear Product Details (5–10% abandonment)

**Solution:**
- Complete description (300+ chars)
- 6–9 images (show every angle)
- Clear specs (volume, formulation, etc.)

**Impact:** -5% abandonment risk

### Combined Mitigation

```
Optimized listing:
- Shipping cost visible: -20% abandonment
- Express option offered: -10% abandonment  
- Complete description: -5% abandonment
- High-quality images: -5% abandonment

Total expected: -40% cart abandonment baseline
= +40% conversion rate lift
```

## 9. Métrica de Performance

### KPIs to Monitor

| Metric | Baseline | Target | Action if Below |
|---|---|---|---|
| CTR (Clicks/Impressions) | 2–5% | 5–8% | Review title/images |
| Conversion (Orders/Clicks) | 2–5% | 5–10% | Clarify description/price |
| Avg. Order Value | R$99.90 | R$120+ | Bundle strategy |
| Questions/100 views | &lt;10 | &lt;5 | Add description detail |
| Review rating | 3.8★ | 4.5★+ | Product quality or response time |
| Cart abandonment (inferred) | 70–80% | 50–60% | Apply drivers mitigation |

### Monitoring Frequency

- Daily: CTR, orders, questions
- Weekly: AOV trends, review responses
- Monthly: Full analytics review, competitor benchmark
